# Virtual Campus VR

A 3D virtual representation of the Hyderabad Institute of Technology and Management (HITAM) campus developed using Blender and Unity.

The project recreates academic buildings, classrooms, laboratories, administrative offices, sports facilities, and outdoor environments, allowing users to explore the campus through an interactive third-person navigation system.

---

## Project Overview

Virtual Campus VR was developed to create an immersive digital version of the HITAM campus. The project combines 3D modeling, environment design, and game development techniques to provide an interactive virtual campus experience.

The virtual environment includes:

- Academic Buildings
- Classrooms
- Computer Laboratories
- Engineering Laboratories
- Administrative Offices
- Sports Facilities
- Outdoor Campus Areas
- Walkways and Landscaped Spaces
