# Virtual Campus VR – Project Summary

## Overview

Virtual Campus VR is a 3D virtual representation of the Hyderabad Institute of Technology and Management (HITAM) campus developed using Blender and Unity. The project was designed to recreate key campus facilities in a digital environment, allowing users to explore academic and administrative areas through an interactive third-person navigation system.

The virtual environment includes classrooms, computer laboratories, engineering laboratories, administrative offices, sports facilities, walkways, and outdoor campus surroundings. The project demonstrates the application of 3D modeling, environment design, asset integration, and game development techniques to create an immersive campus exploration experience.

---

## Objectives

* Develop a virtual representation of the HITAM campus.
* Create realistic indoor and outdoor environments.
* Enable interactive campus exploration through third-person navigation.
* Demonstrate the use of Blender and Unity for large-scale environment development.
* Simulate academic and administrative facilities in a virtual environment.
